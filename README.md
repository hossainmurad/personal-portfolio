HOSSAIN MURAD — PERSONAL PORTFOLIO

FILES
- index.html: page structure and content
- style.css: custom styles, responsive layouts and animations
- script.js: mobile navigation, current year and email-form interaction

HOW TO RUN
1. Extract the project folder.
2. Open index.html in a browser, or open the folder in VS Code.
3. Recommended: install the VS Code Live Server extension and choose “Open with Live Server”.

BEFORE SUBMITTING — PERSONALISE THESE DETAILS
1. Replace your.email@example.com in index.html and script.js with your real professional email address.
2. Replace the Academic Background timeline entry with your real degree, institution and year.
3. Add your actual GitHub and LinkedIn profile URLs to the social links in index.html.
4. Add real project screenshots, published demo URLs and repository URLs when available.
5. If you want a real portrait, replace the abstract portrait area in the hero with your own image.

NOTES
- Tailwind CSS is loaded using its CDN for easy setup; an internet connection is needed for Tailwind utilities and Google Fonts.
- The contact form opens the visitor's default email application. It does not send or store messages on a server.
- Project cards currently describe portfolio concepts and should be updated to match your completed work before final submission.
